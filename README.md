# 城市生活账本 · cityWeChat

> 用数据看城市，用故事讲普通人的生活选择。

公众号自动排期发布工具：提前写好一周内容，自动生成**蓝色数据风**封面 + 文内图，进草稿箱，按每周二/四/日晚定时发送。基于「城市数据与普通人生活变化」赛道规划构建。

## 内容定位

- **核心赛道**：城市数据与普通人生活变化
- **核心读者**：25–45 岁城市生活者及家庭决策者
- **单篇模板**：一个反常识结论 → 一至三组关键数据（标来源与口径）→ 一个普通人案例 → 一项可执行建议 → 一个容易回答的互动问题
- **五个固定母题**：城市对比、普通人账本、人口与婚姻、工作迁徙、热点解释

## 视觉风格

简约大气蓝色基调：深藏蓝 hero 标题卡、深蓝表头 + 斑马纹数据表格、结论前置强调块、蓝色数据信息图配图。三大固定卡片：

- 📌 本篇你可以带走
- 📊 数据来源与口径
- 💬 今日互动

## 目录结构

```
src/
  token.js        access_token 获取 + 缓存
  png.js          纯 Node 生成渐变 PNG（兜底封面）
  cover.js        7 天蓝色系兜底配色
  imagemaker.js   AI 配图（gpt-image-2）+ 微信素材上传
  markdown.js     Markdown → 微信富文本（蓝色数据风渲染器）
  publish.js      封面上传 + 建草稿 + CLI
  scheduler.js    定时发布守护进程
content/
  2026-09-08_to_09-14/   一周稿件（.md，含 frontmatter）+ 选题表.md
```

## 前置准备

1. 安装依赖：`npm install`
2. 复制 `.env.example` 为 `.env`，填入公众号 `APPID` / `APPSECRET`
3. 在公众号后台「设置与开发 → 基本配置」，把本机公网出口 IP 加入 **IP 白名单**（否则报 40164）

## 常用命令

```bash
npm run token           # 测试 access_token 连通性
npm run upload:week     # 本周全部进草稿箱（含封面+文内图）
npm run rebuild:week    # 删旧草稿 + 重生成图片 + 重建
node src/publish.js --only 周二   # 只处理某天
npm run list:drafts     # 查草稿箱
npm run status          # 查本地发布状态
npm run schedule        # 启动定时发布守护进程
npm run publish:now     # 立即检查并发布今天该发的草稿
```

## 发布节奏

每周二、周四、周日晚 20:00 各 1 篇（`.env` 里 `PUBLISH_HOUR` / `PUBLISH_MINUTE` 可调）。首月不追求日更，同一母题至少测试 3 篇后再判断方向。

## 数据合规原则

- 测算类数据一律标注「测算模型 · 非官方数据」，写明口径与假设
- 引用趋势不用未标注年份的具体数字，避免「旧数据讲新故事」
- 案例取得授权或匿名处理，保留核验记录
- 标题不超过正文能支撑的证据，不把相关关系写成因果
